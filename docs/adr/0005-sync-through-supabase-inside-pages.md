# Sync through Supabase inside the Pages app

The Pages app signs in and syncs history itself through Supabase, replacing the separately hosted ChatGPT-sign-in app and its D1 database described in ADR-0002 and ADR-0004. Sign-in is a Supabase email magic link. History is one append-only `training_events` table keyed by `(user_id, id)`, where row-level security lets each account read and add only its own rows: the publishable key in the browser grants nothing more, upload retries are idempotent, and corrections are new events rather than updates. ADR-0002's event model carries over unchanged, with a local offline write buffer and every change naming its prior versions so concurrent edits stay visible conflicts. This keeps one free static app shared between phone and laptop, at the cost of depending on Supabase, whose built-in email service only suits a single personal user.
