# Ticket wrap-ups

**Ticket wrap-ups** in chat follow: what it was for, what changed, how to try it, things for you, then. How to try it gives the URL on the dev server (`http://127.0.0.1:5174/day-by-day/#/…`, such as `#/workout/2026-10-22`), each step and what it should show, and says when a step can't be seen until a later ticket. Every manual step gets the exact command, why it's needed, and where each value comes from. A command that needs the branch's code starts with `cd <worktree path> &&`, and a step that needs `npm run dev` finds it running or says to start it (from a worktree while the main checkout's server holds 5174, on its own port: `npm run dev -- --port 5176 --strictPort`). Then is a paste-ready prompt for the next ticket, never a session card. The wrap-up comes before any push, PR or merge question.
