# Day by Day

Day by Day supports following a training program and understanding training consistency and performance.

## Language

### Program structure

**Program**:
A dated sequence of workouts with a fixed start and end, followed one at a time.
_Avoid_: Plan, routine, roadmap, block

**Workout**:
One day's prescribed training in a program, made up of sections.
_Avoid_: Session

**Section**:
One part of a workout: a single exercise, a superset, a run, or a warm-up, cool-down or mobility item.
_Avoid_: Block

**Superset round**:
One set of each exercise in a prescribed superset, followed by its prescribed rest.
_Avoid_: Single exercise set

**Rest day**:
A day on which the program schedules no workout.
_Avoid_: Planned rest, scheduled rest, recovery day

### Dates and consistency

**Original date**:
The date the program assigns to a workout. It never changes, even when the workout is moved.
_Avoid_: Scheduled date, actual training date

**Scheduled date**:
The date a workout is currently due: its original date, or the date it was last moved to.
_Avoid_: Planned date, revised scheduled date, actual training date

**Actual training date**:
The date a workout was actually performed. For a completed workout it is the day its last set was ticked, which may differ from its scheduled date.
_Avoid_: Scheduled date

**Missed workout**:
A workout whose scheduled date has passed without it being completed.

**Deadline**:
The date by which a workout must be completed to count as on time. It is the workout's scheduled date until the workout is missed; after that it stays at the first scheduled date it missed, however often it is moved.
_Avoid_: Original date

**On-time completion**:
A completed workout whose actual training date is on or before its deadline.
_Avoid_: Any recorded activity, partial workout

**Training streak**:
The number of consecutive on-time completions. Rest days never break it; a workout whose deadline passes without an on-time completion ends it.
_Avoid_: Daily workout streak

**Consistency**:
How closely training follows the program's scheduled dates, with rest days counting as part of the program rather than as gaps.
_Avoid_: Performance, daily workout streak

### Completion

**Set completion**:
A confirmation that a prescribed set was performed. A set with a range or a max test can be completed without a number.
_Avoid_: Set result, prescribed target

**Completed workout**:
A workout with every exercise set ticked. Warm-up, cool-down and mobility items are optional.
_Avoid_: Finished workout

**Partial workout**:
A started workout that was finished early, or not completed by its scheduled date.
_Avoid_: Partial session, completed workout

**Workout clock**:
A stopwatch for a whole workout. Ticking the first set while training starts it, or you start it yourself; it can be paused and resumed, and it stops when the workout is completed or finished early, or after three hours with nothing logged.
_Avoid_: Session timer, rest timer

**Workout duration**:
The time a stopped workout clock shows, as recorded or as corrected by hand. A workout without one was not timed.
_Avoid_: Session length, run time

**Imported completion**:
A workout marked complete in the original version of the app. It counts as a completed workout but has no actual training date or set results.
_Avoid_: Legacy completion

### Exercises

**Exercise**:
A movement tracked under one name across every program, such as Pull-Ups, Chin-Ups or Calf Raises. Its easier and harder versions are variations, not separate exercises.
_Avoid_: Movement, chain

**Variation**:
A version of an exercise at one level of difficulty, such as tucked, decline, single-leg or weighted.
_Avoid_: Stage, tier, level

**Progression chain**:
An exercise's variations in order of difficulty, such as Push-Ups, then Decline, then Archer. Advancing means moving to the next variation.
_Avoid_: Stage list, tiers

**Assistance**:
Support that makes a set easier without changing its variation, such as a band or a chair.
_Avoid_: Variation, setup

### Performance

**Performance**:
Measured training results, such as repetitions, hold duration, or exercise difficulty, that can be compared over time.
_Avoid_: Consistency, completion count

**Set result**:
The repetitions or hold duration recorded for an individual set, including the exercise variation, assistance, and side when relevant: the prescribed number when a fixed-target set is ticked, otherwise the number entered.
_Avoid_: Prescribed target, exercise checkbox

**Run result**:
The actual distance and elapsed time recorded for a run.
_Avoid_: Planned distance, target pace

**Comparable personal best**:
A person's best recorded result for the same exercise variation and measurement conditions.
_Avoid_: Highest repetition count across all variations

**Test**:
A set that measures a best effort, such as a pull-up max or a max dead hang. An exercise's test result is its best set in the last week that tests it, compared with the first week that tested it when that came earlier.
_Avoid_: Assessment, benchmark set

**Program summary**:
What Today shows after a program's last day until the next program starts: workouts completed out of planned, best streak, personal bests and test results.
_Avoid_: Program report, recap

**Progression suggestion**:
A recommendation to advance exercise difficulty based on recorded results and the program's progression rule. An advancement takes effect only after confirmation.
_Avoid_: Automatic advancement
