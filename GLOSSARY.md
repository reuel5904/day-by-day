# Day by Day

Day by Day supports following a workout plan and understanding training consistency and performance.

## Language

**Consistency**:
How closely training follows the planned schedule, accounting for scheduled rest.
_Avoid_: Performance, daily workout streak

**Performance**:
Measured training results, such as repetitions, hold duration, or exercise difficulty, that can be compared over time.
_Avoid_: Consistency, completion count

**Set result**:
The actual repetitions or hold duration recorded for an individual set, including the exercise variation, assistance, and side when relevant.
_Avoid_: Prescribed target, exercise checkbox

**Planned date**:
The date a workout is scheduled to be performed. It changes only when the workout is deliberately rescheduled.
_Avoid_: Actual training date

**Actual training date**:
The date a workout was actually performed, which may differ from its planned date.
_Avoid_: Planned date

**Partial session**:
A finished workout with one or more prescribed sets left unfinished or skipped.
_Avoid_: Completed session

**Training streak**:
A run of completed scheduled training days, with scheduled rest preserving the run and an uncompleted training day breaking it.
_Avoid_: Daily workout streak

**Progression suggestion**:
A recommendation to advance exercise difficulty based on recorded results and the routine's applicable progression rule. An advancement takes effect only after confirmation.
_Avoid_: Automatic advancement

**Run result**:
The actual distance and elapsed time recorded for a run.
_Avoid_: Planned distance, target pace

**Comparable personal best**:
A person's best recorded result for the same exercise variation and measurement conditions.
_Avoid_: Highest repetition count across all variations

**Superset round**:
One set of each exercise in a prescribed superset, followed by its prescribed rest.
_Avoid_: Single exercise set


**Original date**:
The date assigned to a workout in the original program, retained when it is rescheduled.
_Avoid_: Revised scheduled date, actual training date

**Revised scheduled date**:
The date deliberately selected when an individual workout is moved.
_Avoid_: Original date, actual training date

**On-time completion**:
A fully completed workout performed on or before its applicable scheduled deadline. Moving an already missed workout does not remove the earlier missed deadline.
_Avoid_: Any recorded activity, partial session


**Set completion**:
A confirmation that a prescribed set was performed. It can be recorded without a measured repetition count, duration, or distance.
_Avoid_: Set result, prescribed target
